# Credit Score Projection

This application is hosted on Streamlit to facilitate UI programming for myself; if I decide to upgrade this project beyond an independent hobby project, then this application will be hosted on a software of its own.

## How does it work?

This application was made for Financial Counselors to develop plans and examine projections for a client's credit score trajectory.
*Please keep in mind that this program is not 100% accurate, and further modifications will be added to achieve near-perfection realism.*

## Future Updates?

Dynamic FICO formulas because credit score changes are not linear, meaning it is not as easy to go from 750-780 as 540-570.
*Also different types of inquiries sometimes use different types of FICO versions*

I am planning to integrate an AI that provides a more in-depth examination for a client.
